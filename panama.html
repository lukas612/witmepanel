ACTUALIZAR DESDE EBI-PAC
  1. Inicia sesión en factura.ebi-pac.com/invoices con tu usuario del portal.
  2. Abre las herramientas de desarrollador del navegador (F12) → pestaña Network (Red) → filtra por Fetch/XHR.
  3. Recarga la tabla de facturas (o cambia de página) para que se dispare la petición invoices/list.
  4. Haz clic derecho sobre esa petición → Copy → Copy as cURL, y pega aquí abajo el comando completo (o solo el valor del header Cookie).
  5. Pulsa Actualizar. Esto no guarda la cookie en ningún sitio — se usa una vez y se descarta.
Qué es esto: lo realmente facturado por la entidad de Panamá, según EBI-PAC (su proveedor autorizado de facturación electrónica) — mismo concepto que "Facturado (Holded)" para España, pero sin impuesto (estas facturas de operación extranjera no llevan ITBMS, así que el importe ya es neto) y en USD.

Por qué se actualiza a mano: el Web Service de EBI-PAC (pensado para integraciones) no tiene ningún método para listar o consultar facturas por fecha — solo operaciones sobre un documento ya conocido (enviar, descargar, anular…). La única forma de ver el listado es el portal web humano, protegido con CAPTCHA en el login, así que no existe ningún token de API que se pueda guardar y usar en un proceso automático diario como el de Holded. Por eso hace falta iniciar sesión a mano de vez en cuando (semanal o mensual, cuando convenga) y pegar la cookie de esa sesión aquí para forzar la actualización — el resto (paginar el listado completo, sumar por mes, guardar) lo hace el botón.

Solo ingresos, todavía no gastos: EBI-PAC es exclusivamente para las facturas que emite Panamá — no expone nada de sus compras/gastos. Cuando llegue esa información (por otra vía) se añadirá un "Comprado (Panamá)" aparte, igual que existe para España.
